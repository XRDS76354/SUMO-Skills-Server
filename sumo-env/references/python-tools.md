# Python Tools and Packages

## SUMO tools dependencies
- Install Python requirements for tools:
  pip install -r $SUMO_HOME/tools/requirements.txt

## Python packages (optional)
- Install packaged SUMO or libraries:
  pip install eclipse-sumo
  pip install traci sumolib libsumo

## Virtual environment (optional)
- Create and activate:
  python -m venv .venv
  .venv\Scripts\activate  # Windows
  source .venv/bin/activate  # Linux/macOS
